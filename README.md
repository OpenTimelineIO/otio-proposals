# OpenTimelineIO Proposals

OpenTimelineIO Proposals (OTIPs) are public design documents for significant changes to OTIO, including serialized schemas, interchange behavior and project-wide processes.

- Browse the [proposal index](proposals/README.md) or follow [open proposal pull requests](https://github.com/OpenTimelineIO/otio-proposals/pulls).
- Start with the [contributing guide](CONTRIBUTING.md) and [proposal template](templates/proposal.md).
- Read the proposed review process in [OTIP-000](proposals/000-process/README.md).

The November 19, 2026 Technical Steering Committee (TSC) notes record the name `otio-proposals`. The workflow in OTIP-000 is open for TSC review. Publication of a design and delivery of an implementation are separate milestones. [November 19 TSC notes](https://docs.google.com/document/d/1L4Y_qfVc1lEyHNdpHA-Lrnzb2DEhO77OQq3rxVli4a4/edit)
